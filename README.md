# Otros siete elementos

Un acertijo de pensamiento lateral. Los elementos químicos vuelven a un sorteo con siete premios, y solo se sabe que
el xenón fue el segundo; el vanadio, el cuarto, y el magnesio, el último. ¿Puedes proponer una lista de ganadores que
tenga sentido? Juego web autónomo en un único `index.html`.

**Jugar:** https://spyder-cripto.github.io/otros-siete-elementos/

![Otros siete elementos](captura.png)

## Cómo se juega
- Toca una casilla libre del podio y después un elemento de la tabla periódica, o al revés. En el ordenador también
  puedes arrastrar.
- El xenón (2.º), el vanadio (4.º) y el magnesio (7.º) ya están en su sitio.
- Cuando tengas los siete, pulsa **Comprobar**: te dirá si la lista vale, pero no qué casilla falla.
- **Pista** te ayuda un poco más cada vez que la pulsas. **Solución** enseña una lista que vale.
- Hay muchas listas posibles: basta con que la tuya siga la lógica del sorteo.
